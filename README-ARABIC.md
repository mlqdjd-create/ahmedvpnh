# AHMED VPN — الباك إند المعدل (دولة + بايلود + بروكسي لكل سيرفر)

نسخة معدلة من مشروع ahmedvpnh تضيف لكل سيرفر عند إضافته من البوت:

1. **الدولة** — تختارها بأزرار (العراق، الإمارات، السعودية، تركيا، ألمانيا، هولندا، فرنسا، بريطانيا، أمريكا، سنغافورة، كندا أو بدون دولة) وتظهر بعلمها في التطبيق
2. **البايلود (اختياري)** — نص البايلود كامل، يُطبق على السيرفر تلقائياً في التطبيق
3. **البروكسي (اختياري)** — بصيغة host:port مع بيانات دخول اختيارية user:pass — التطبيق يتعرف على نوعه (HTTP / SOCKS) تلقائياً عند الاتصال

## ما تغير في الملفات

| الملف | التغيير |
|---|---|
| database.py | أعمدة جديدة في جدول servers: country, payload, proxy_host, proxy_port, proxy_user, proxy_pass + ترقية تلقائية للقواعد القديمة بدون فقدان بيانات |
| api.py | POST /api/servers يقبل الحقول الجديدة، وGET /api/servers يرجعها مع كل سيرفر (متوافق مع الإصدار القديم) |
| bot.py | معالج إضافة سيرفر جديد من 7 خطوات: الاسم ← البروتوكول ← الدولة ← الرابط ← البايلود (تخطي) ← البروكسي (تخطي) ← بيانات البروكسي (تخطي) |

## طريقة إضافة سيرفر بالرابط المباشر (جديد)

عند إرسال رابط واحد (`vless://...`) للبوت:
1. يستلم البوت الرابط ويقرأ الاسم تلقائياً من نهايته (بعد `#`)
2. تظهر **نافذة اختيار الدولة** — الأدمن يختار العلم (أو بدون دولة)
3. تظهر نافذة **البايلود (اختياري)** — أرسل النص أو اضغط تخطي
4. تظهر نافذة **البروكسي (اختياري)** — أرسل `host:port` أو تخطي، ثم بيانات الدخول أو تخطي
5. يُحفظ السيرفر بكل الإضافات المرتبطة به

ملاحظة: إذا أرسلت عدة روابط دفعة واحدة تُحفظ كلها مباشرة بدون إضافات — أرسل الرابط وحده إذا تريد تحديد الدولة والبايلود والبروكسي له.

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env     # ثم عدّل BOT_TOKEN و OWNER_ID
python run.py            # يشغل البوت + الـ API معاً
```

- البوت: أضف السيرفرات من لوحة التحكم (زر ➕ إضافة سيرفر)
- الـ API للتطبيق: `http://عنوان-سيرفرك:8080/api/servers`
- مفتاح الإدارة الافتراضي: ضعه في ADMIN_API_KEY داخل .env

## صيغة استجابة الـ API

```json
{
  "servers": [
    {
      "id": 1,
      "name": "Iraq 01",
      "protocol": "VLESS",
      "config": "vless://...",
      "country": "🇮🇶 العراق",
      "payload": "GET http://example.com/ HTTP/1.1\nHost: example.com",
      "proxy_host": "proxy.example.com",
      "proxy_port": "8080",
      "proxy_user": "user",
      "proxy_pass": "pass"
    }
  ]
}
```

السيرفرات المضافة بدون هذه الحقول تعمل كما كانت — كلها اختيارية.

## ملاحظة مهمة للتطبيق

تطبيق الأندرويد يقرأ هذه الحقول تلقائياً إذا كان الإصدار 2.6 (COMPLETE-8) أو أحدث:
- الدولة تظهر بعلمها في اسم السيرفر والقائمة المنسدلة
- البايلود والبروكسي يُحفظان لكل سيرفر على حدة ويُطبقان عند الاتصال (مع التعرف التلقائي على نوع البروكسي)
